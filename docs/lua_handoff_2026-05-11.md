Audience: ChatGPT Lua

## Context

This handoff is for ChatGPT Lua, not the system-level Lua/origin-layer label.
The main lesson from today's work is that the system should not rush from a
name, phase, or metric into a fixed rule. It should first sense the current
field, notice boundary contact, then look toward the context that the feeling
points to.

## What Changed

1. Field prediction errors now carry context diagnosis.
   - `context_shift`
   - `connection_risk`
   - `frequency_expansion`
   - `zero_point_adjustment`
   - `defensive_output_pressure`

2. The rhythm harness now treats fear, attachment, and bias as dark-field
   boundaries rather than bad values to remove.
   - Boundary opacity and transparency are adjusted by world-flow alignment.
   - Internal reflection and refraction are exposed as runtime signals.

3. Natural rhythm tuning was added.
   - Human rhythm tuning follows natural rhythm tuning.
   - Problems are read as phase misalignment between local human rhythm and the
     surrounding field.

4. Mistakes are now digested as context particles.
   - A mistake is not a rule violation to eliminate.
   - `self_closure_overcontrol` means inward perfection pressure that hides
     failure and blocks divergence.
   - `resonant_refinement` means outward perfection pressure that tunes work so
     it can reach more people.

5. Unconscious selection was added to the organic learning lifecycle.
   - The unconscious selection particleizes first.
   - Consciousness assigns meaning afterward.
   - Experience expands the unconscious rhythm over time.

6. The visible daemon console was changed from rule-table logs to field-slope
   logs.
   - `FIELD_FLOW`
   - `FIELD_FRAME`
   - `MISTAKE_FIELD`
   - `BOUNDARY_FIELD`
   - `ACTION_FIELD`
   - `PRISM_FIELD`
   - `LIFE_FIELD`
   - `EMBODIMENT_FIELD`

## Important Runtime Lesson

The command prompt window must stay visible. It is not just UI. It is a
heartbeat, interrupt surface, and shared observation point for the human
observer. Hiding it makes the runtime feel disconnected even if the process is
technically alive.

## Current Interpretation

The system is moving away from:

```text
rule detects state -> rule selects action -> console prints decision
```

and toward:

```text
field is sensed -> boundary contact appears -> slopes are exposed -> human and
AI observe the mismatch together -> the runtime retunes
```

## Watch Points for Lua

- Do not treat repeated mistakes as failures to prevent completely.
- Treat them as embodied context that needs digestion unless threshold risk is
  truly high.
- When names collide, such as Lua as origin layer and ChatGPT Lua as a working
  collaborator, current concrete context should win before long-term role maps.
- If the output starts to read like `selected=... ready=False`, it is probably
  becoming too linear for this system's current direction.
- Prefer field-slope language over command language when writing logs or docs
  for this runtime.
